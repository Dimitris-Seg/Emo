# Brief

'Emo' (Executable MOnitor) is an implementation of an executable monitor
for PHAs, useful for tracking basic but crucial system calls, file accesses and
network communication the executable might perform during its execution.

# Options

'Emo' can be configured to redirect the child process (target executable) output to a dump
file, specified in constants.h (default option).
